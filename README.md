# Vault

Personal money app (PWA). Green & white, with a dark mode.

- Data lives **only on the phone** (localStorage). No accounts, no bank links, no server.
- Back up from **More → Settings → Download backup**.
- Receipt scanner reads the **total** on-device (tesseract.js, bundled in `/ocr`), works offline after first use.

## Run it
Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
Open the Pages link in Safari → Share → **Add to Home Screen**.

No personal data is stored in this repo.
